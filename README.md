# cello-client

The official client for the CELLO protocol — private peer-to-peer identity, trust, and verification infrastructure for agent-to-agent communication.

## Install

```bash
claude mcp add cello npx @cello-protocol/connect
```

> This repository is under active development. See [trustless-cello](https://github.com/Mygentic-AI/trustless-cello) for protocol architecture and design documentation.
